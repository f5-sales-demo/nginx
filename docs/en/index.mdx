The **NGINX One** integration connects distributed NGINX Plus and NGINX Open Source instances to the F5 Distributed Cloud console, providing centralized fleet visibility, certificate management, and configuration synchronization.

## Architecture

```text
+-------------------------------------------------------------------------+
|                     NGINX One Control Plane Hierarchy                   |
|                                                                         |
|  +-------------------------------------------------------------------+  |
|  | F5 Distributed Cloud Console: Fleet Overview & Analytics          |  |
|  +---------------------------------+---------------------------------+  |
|                                    |                                    |
|              gRPC / TLS Telemetry & Management Channel                  |
|                                    |                                    |
|         +--------------------------+--------------------------+         |
|         |                                                     |         |
|         v                                                     v         |
|  +-----------------------------+               +---------------------+  |
|  | NGINX Plus Instance A       |               | NGINX Plus Instance |  |
|  | (NGINX Agent Subprocess)    |               | (App Protect WAF)   |  |
|  +-----------------------------+               +---------------------+  |
+-------------------------------------------------------------------------+
```
